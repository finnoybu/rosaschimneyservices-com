ROSAS CHIMNEY SERVICES - WEBSITE
rosaschimneyservices.com

WHAT THIS IS
A complete static website: plain HTML, CSS and JavaScript. No database, no
server code, nothing to install. Any web host can serve it.

TO PUT IT ONLINE
1. Unzip this folder.
2. Upload EVERYTHING inside it (index.html, the other .html files, the
   "assets" folder, robots.txt, sitemap.xml and .htaccess) to the web root
   of your hosting account. On most hosts that folder is called
   "public_html", "www" or "htdocs".
3. Keep the folder structure exactly as it is.
4. Visit https://rosaschimneyservices.com to confirm it loads.

Works on any standard host, including GoDaddy, Bluehost, Hostinger,
SiteGround, Cloudflare Pages, Netlify and GitHub Pages (drag and drop the
unzipped folder). The .htaccess file is only used by Apache-based hosts and
is harmless elsewhere.

TO PREVIEW BEFORE UPLOADING
Double-click index.html. It opens in your browser and all links work.

COMMON EDITS
- Phone, email, hours: search the .html files for "431-9629",
  "rosaschimneyservices@gmail.com" or "7 AM to 7 PM" and replace.
- Colors: the top of assets/css/styles.css lists every color.
- Pictures: the illustrations live in assets/img. Real job photos can
  replace hero.svg and chimney-detail.svg (keep the same file names, or
  update the <img> tags).
